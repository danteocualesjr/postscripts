I picked up a book today. It's by an author named Henry Fielding. I bought it mainly because the title has my name on it: Tom.

It's pretty thick, too. The first chapter is practically unreadable. The second one is more comprehensible. And it gets better from there. I wonder if it has something to do with my modern sensibilities and, I'm ashamed to admit, my reading comprehension.

Fielding's sentences are intellectually pleasurable to read. It seems men from earlier centuries knew how to write, and write well. Eighteenth-century prose is beautiful. I can see no better way to write than theirs. I want to write like them.
